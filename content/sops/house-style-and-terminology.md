# House Style and Terminology

## Steps

1. Use British English spelling across all brands.
2. Write bank names as registered; abbreviate only after first use.
3. Express currency as ISO code plus figure, e.g. USD 2.4 billion.
4. Avoid hype words listed in the brand guide appendix.
5. Raise new terminology with the style committee monthly.
