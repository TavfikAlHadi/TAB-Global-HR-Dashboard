# Venue Contracting

## Steps

1. Shortlist three venues against the event brief.
2. Run site visits and score on the venue checklist.
3. Negotiate cancellation, attrition and force majeure clauses.
4. Route contract to Finance & Admin for approval before signing.
5. File signed contract in the event folder.
