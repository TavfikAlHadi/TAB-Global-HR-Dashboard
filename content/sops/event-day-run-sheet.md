# Event Day Run Sheet

## Steps

1. Issue the final run sheet to all crew by T-2 days.
2. Hold crew briefing 90 minutes before doors open.
3. Stage manager calls every session change on radio.
4. Log incidents in the event incident register.
5. Debrief within 48 hours and record lessons learned.
